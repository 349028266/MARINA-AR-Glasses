# MARINA-AR-Glasses
A repository for an open source AR glasses project. MARINA is a project aiming to create an optical device attachable or wearable that will provide an AR experience similar to other hardware in the field. The project was simply started because it seemed really cool, and I thought building one would be awesome.

# Development Stages
## 1. Planning and Design Stage (current stage)
planning out the design of the glasses. Drawings, pseudocode, CAD files, etc.

## 2. Building Stage
Building and obtaining all the components necessary to build the glasses.
